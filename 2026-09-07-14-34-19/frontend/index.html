Dijkstra's Algorithm Internal Working & Mathematical Proof

Dijkstra computes exact full-network shortest paths on dynamic SUMO graph G(t) using priority-queue node relaxation.

1. Edge Weight & Path Metric Equations

Edge Weight: w_e(t) = T_e(t) = \frac{L_e}{\max(v_e, 0.1)} \times (1 + \text{penalty}_e)
Node Relaxation: d[v] = \min(d[v], d[u] + w(u, v)) \quad \forall v \in \text{Adj}(u)
Total Travel Time: T_{\text{total}} = \sum_{e \in \text{Path}} T_e(t)
Total Distance: D_{\text{total}} = \sum_{e \in \text{Path}} L_e
Average Speed: v_{\text{avg}} = \frac{D_{\text{total}}}{\max(T_{\text{total}}, 0.1)}
